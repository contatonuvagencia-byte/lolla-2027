# Lolla 2027

Planner, roteiro e lista de compras da viagem pro Lollapalooza Brasil 2027.

- `site/`: as 3 páginas (Planner, Roteiro e Compras), publicadas no GitHub Pages
- `supabase/migrations/`: tabela `lolla_state` com RLS (cada pessoa só vê e edita os próprios dados)
- Login por e-mail e senha pelo Supabase Auth

Os dados pessoais ficam só no Supabase, nunca neste repositório.
